# Legacy R6 reference data

`bike_params_r6.csv` is retained from an earlier lap-time simulation project as
reference data only. The future clean-sheet motorcycle model will use a more
explicit configuration. These values must not automatically be treated as
validated physical data. In particular, `T_peak` is not a torque-versus-RPM
curve. The legacy wheelie and braking limits will eventually be replaced or
supplemented with geometry-based limits.
